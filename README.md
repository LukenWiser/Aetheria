# Aetheria: Quantum Strike

A 3D cel-shaded space shooter by **Luken Wiser**. Play it at https://lukenwiser.github.io/aetheria/

- `index.html` - the built game (this is what GitHub Pages serves)
- `src/` - the source, split into numbered chunks
- `build.py` - joins `src/` into one HTML file: `python3 build.py index.html`
